One-Time Setup

Connect a free Firebase database so photos sync across everyone's phones.

1 Go to console.firebase.google.com → sign in with Google → Add project
2 In left menu → Realtime Database → Create Database → choose location → "Start in test mode" → Enable
3 Copy the URL shown — it looks like:
https://myapp-12345-default-rtdb.firebaseio.com

🔒 URL is saved on your device only. The database is yours.
